# Verify client before reply

1. Ask for the inbound message (paste).
2. Run `check_inbound_message`.
3. Summarize risk level + top flags; link the LiveProof report.
4. If they need a human presence check (remote hire / marketplace meetup), send them to https://liveproof.nyttolabs.com/request
